Polytomic is a data integration platform providing no-code data syncing between databases, data warehouses, and SaaS applications. The Polytomic REST API exposes connections, syncs, models, bulk syncs, identity, schemas, and webhooks for programmatic management of data movement.

**Areas:** Data Integration · Reverse ETL · Unified API · ELT · Data Sync

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Polytomic: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
